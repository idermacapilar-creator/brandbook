Capítulo 01

Filosofía
de Marca

Capítulo 04

Grilla y
Composición

El sistema compositivo de IDERMA se basa en el uso de una grilla de 12 columnas adaptable a cada formato. Los márgenes de seguridad son obligatorios para garantizar que ningún elemento clave quede cortado en impresión o pantalla.

Diagrama de Grilla · Post Feed Instagram / Facebook (1:1 · 1080×1080px)

Margen de seguridad (6% de cada lado)
Zona de riesgo — sin texto ni logotipos
Zona activa — texto, logo, CTAs

Principios de Composición

✓ SÍ hacer

El logotipo siempre en la esquina superior izquierda o centrado. Nunca en una posición diferente en publicaciones de feed.

✕ NO hacer

Colocar el logo en la esquina inferior derecha, donde compite visualmente con el ícono de Instagram o las etiquetas de TikTok.

✓ SÍ hacer

El titular principal en la zona inferior (2/3 inferiores del formato) para generar jerarquía visual y permitir que la imagen respire.

✕ NO hacer

Saturar la imagen con más de 3 bloques de texto distintos. Cada publicación debe tener UN mensaje principal claro.

✓ SÍ hacer

Usar el gradiente Navy→Dark como overlay sobre fotografías para mantener coherencia de marca sobre cualquier imagen.

✕ NO hacer

Usar fotografías sin tratamiento de overlay. Toda imagen debe pasar por el filtro azul-oscuro para mantener la identidad.

Música y Sonido

Reels / TikTok
Tendencias + Identidad

Música trending de la plataforma. Se permite adaptar el ritmo de corte al audio. Siempre mantener el estilo visual aunque el audio sea externo.

Videos Institucionales
YouTube · Presentaciones

Música instrumental: electrónica suave / ambient / neoclásica. Bpm: 80–110. Evitar música con letra en español para no competir con el narrador.

Principios de Motion Graphics

◇
Transiciones

Deslizamiento lateral suave (0.3s ease-out) o fade cruzado (0.4s). Nunca wipes o transiciones con efectos de 3D bruscos. El movimiento refuerza la fluidez premium.

◈
Animación de Texto

Letra por letra con fade-in ascendente (translateY 10px → 0). Delay entre palabras: 0.08s. El dorado aparece siempre después del blanco para generar contraste dinámico.

◉
Overlay Marca

Partículas doradas flotantes (opacidad 8–15%). Grid sutil animado sobre footage médico. El logo siempre en la esquina superior izquierda con fade a 80% de opacidad.
